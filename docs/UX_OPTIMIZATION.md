# 用户体验优化记录（0.6.0）

## 任务从“瞬时状态”升级为“可追踪记录”

旧版本主要在通道卡片显示当前进度。关闭抽屉、筛选通道或应用异常退出后，用户难以追踪任务发生了什么。

0.6.0 增加任务中心：

- 顶栏随时打开；
- 统一显示运行中和历史任务；
- 支持搜索文件、通道和路径；
- 显示耗时、写入数、替换数和错误原因；
- 失败、取消、中断和成功任务均可重新运行；
- 失败时可自动打开任务中心。

## 删除行为从“删除目录”改为“按清单删除”

“一键删除解压文件”是高风险操作。直接删除输出目录可能误删用户原有文件，因此界面和后端共同采用任务清单：

- 按任务显示“删除解压文件”；
- 任务中心可批量删除全部可删除结果；
- 默认保护曾覆盖旧内容的文件；
- 删除前说明预计范围；
- 已删除状态在任务记录与通道文件之间同步。

## 项目工具放在独立设置页

用户提供的 BAT 和 Claude 高权限命令不属于普通解压选项，因此没有塞入每张通道卡片，而是放入“设置 → 项目工具”。

- 可手动输入或选择项目目录；
- 支持生成 BAT、打开目录、一键启动 Claude；
- 覆盖 BAT、生成后打开目录、启动前确认均可独立设置；
- 通道高级区域也提供使用当前输出目录的快捷操作。

## 设置自由度

新增设置包括：

- 任务历史保留数量；
- 失败时自动打开任务中心；
- 删除结果前确认；
- 是否删除曾替换旧内容的文件；
- Claude 项目默认目录；
- 是否覆盖同名 BAT；
- 生成 BAT 后是否打开目录；
- Claude 高权限模式启动前确认。

## 图标设计

新图标使用三条水平项目通道、中央拉链/解压轨道和底部输出托盘，强化“横向多通道项目管理 + 汇聚解压”的识别。Windows ICO 包含多种小尺寸，避免任务栏和资源管理器中只缩放单张大图。

## 仍可继续优化的体验

- 任务中心日期分组和批次视图；
- 解压前真实目录树预览；
- 文件数量超过 500 时虚拟滚动；
- 系统通知和任务结束提示音；
- 诊断包一键导出；
- 首次使用引导，解释输出容器、层级和安全删除差异。
