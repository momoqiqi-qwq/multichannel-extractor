# 解压台 0.8.5 发布说明

## 设置搜索升级

设置抽屉的搜索现在可以直接搜索具体设置项，而不只是筛选左侧分类。支持中文名称、拼音首字母/缩写和常见英文关键词，例如 `bf` 可找到并发相关设置，`gjl` 可找到工具栏相关设置，`rz` 可找到日志相关设置。

点击搜索结果后，应用会自动切换到正确的设置分类，滚动到对应控件，聚焦可操作元素并短暂高亮目标；按 Enter 可直接跳到首个结果。

## 更多可见性设置

“界面与字体”新增“工作区按钮显示”区，可独立控制：顶部并发控制、快捷设置、项目入口、任务入口、日志入口、工作区搜索、工作区筛选和快捷键提示。

完整设置按钮始终保留，避免用户因隐藏入口而无法重新开启功能。紧凑设置侧栏也继续保留搜索输入框。

## 兼容性

package、Tauri、Cargo 和应用内版本统一为 `0.8.5`。配置架构保持 v9；新字段均有默认值，因此已有 0.8.x 配置可以直接加载，不需要强制迁移。
