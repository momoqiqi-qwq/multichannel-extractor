# 解压台 0.8.6 建议规划

## 主题：工作区布局自定义 + 设置搜索 2.0

0.8.5 已经解决“能搜到、能直达、能隐藏入口”。0.8.6 建议继续把这套能力做成真正可配置的工作台，而不是马上堆更多业务开关。

### 1. 顶栏与工具栏拖拽排序

允许项目、任务、日志、快捷设置、并发控制等入口自由排序；提供“恢复默认布局”。

### 2. 设置收藏与最近使用

搜索结果支持收藏常用设置，并记录最近调整过的设置；常规页增加“我的常用设置”。

### 3. Ctrl / Cmd + K 命令面板

统一搜索设置、通道操作、任务中心、项目中心和常用动作，支持方向键选择、Enter 执行、Esc 关闭。

### 4. 单项恢复默认

每个设置项提供“恢复默认值”，避免只能整页或全局重置。

### 5. 界面方案导入导出

把主题、背景、按钮显示、工具栏顺序等保存为“界面方案”，与业务通道配置分开导入导出。

### 6. 自动化测试补强

为设置搜索、缩写匹配、跳转定位、入口显示/隐藏和布局顺序增加组件级测试；Windows CI 中执行 Vue 类型检查、Rust 检查和 Tauri 构建。

## 建议优先级

优先做 1、3、4。这样 0.8.6 会明显提升“自由度”和操作效率，同时不会改变解压核心逻辑，回归风险较低。
