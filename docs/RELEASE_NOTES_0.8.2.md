# 解压台 0.8.2 发布说明

## 项目中心

- 成功解压后自动把实际输出目录加入项目中心；同一路径不会重复创建，只会刷新来源与最近活动时间。
- 支持手动添加任意项目目录。
- 支持项目置顶、进行中/暂停/归档状态、标签、备注、搜索与状态筛选。
- 项目卡片可打开目录、复制路径、生成 Claude DAT、通过 DAT 启动 Claude，或仅从项目中心移除记录。
- 移除项目记录不会删除磁盘文件；清理归档项目会保留已置顶项目。
- 项目数据独立保存在 `multichannel-extractor-projects-v1`，避免继续扩大工作区主状态结构。

## 用户体验

- 顶部增加“项目”入口，并显示置顶项目数或进行中项目数。
- 新增 `Ctrl+Shift+P` 快捷键打开项目中心。
- 项目、任务、日志、设置和快速设置保持互斥；按 Esc 可统一关闭。
- 项目操作提供忙碌状态、空状态、复制成功提示和错误提示。
- 状态栏增加项目总数。

## 工程结构

- 新增独立 `projectCenter` Pinia store，项目领域状态不再继续堆入 `channels.ts`。
- 新增独立 `ProjectCenterDrawer.vue` 与 `project-center.css`，降低主界面和任务中心耦合。
- 新增 `check-082.mjs`，验证版本一致性、项目类型、持久化、自动收录、入口和样式。

## 版本

- npm、Tauri、Cargo 与应用内版本统一为 `0.8.2`。
- 配置架构仍为 v9；项目中心使用独立存储，不要求迁移现有工作区配置。
