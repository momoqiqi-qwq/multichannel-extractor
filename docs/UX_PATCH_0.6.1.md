# 解压台 0.6.1 UX 补丁 — 背景与通道设置体验优化

## 本次改进

- 背景图片默认使用“智能铺满”，随窗口尺寸变化保持覆盖并减少边缘露底。
- 增加“显示背景图片”总开关，关闭时保留图片文件与其他参数。
- 增加“通道背景穿透”开关与通道不透明度滑杆，可在背景可见性和文字可读性之间调整。
- 修复吸顶搜索工具栏层级高于设置抽屉的问题；设置、日志和任务中心现在互斥打开。
- 通道设置由错误的四列布局改为三张对齐设置卡，并在中等宽度下自动切换为两列、窄窗口切换为单列。
- 高级设置、项目工具和通道底部操作支持自动换行，减少横向滚动和大块空白。

## 兼容说明

旧版设置会自动补齐新增字段，不需要清空本地配置。
