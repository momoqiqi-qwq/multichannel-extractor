# 解压台 0.7.0 发布说明

## 版本主题

0.7.0 将重点从“界面可用”推进到“任务可恢复、开始可预判、运行可控制”。本版新增任务级中断恢复、开始前预检查、输出路径树、暂停继续、文件优先级、通道模板导入导出、剩余时间估算、背景焦点拖动和可搜索总设置。

## 新功能

### 1. 任务级中断恢复

- 任务中心历史升级为 `jieyatai-task-history-v2`。
- 排队、处理中和暂停任务在应用重新启动时自动转为“异常中断”。
- 任务记录保存不含密码的 `jobSnapshot`，可恢复源路径、目标路径、层级模式、冲突策略和完成动作。
- 恢复入口位于工作区横幅、任务中心、总设置的“常规”和“自检与恢复”。
- 支持按设置自动恢复不需要密码的中断任务。
- 密码只保存“曾使用密码”标记，不保存明文；相关任务恢复到工作区后要求重新输入。

这是任务级重新提交，不是压缩流字节级续解。

### 2. 开始前预检查

新增 Rust 命令 `preflight_jobs`，逐任务检查：

- 源文件存在性和格式支持；
- ZIP、7Z、RAR 密码输入提示；
- 最终输出路径是否可规划、是否被普通文件占用；
- 目标目录是否已有内容及当前冲突策略；
- 目标磁盘可用空间；
- 压缩包体积、空间估算倍率和最低保留空间。

错误项阻止开始，警告项允许确认后继续。浏览器预览模式无法访问本地磁盘时会退化为路径预览，并明确显示提示。

### 3. 树形输出预览

新增 `StartReviewDialog.vue`：

- 展示源压缩包到最终输出根目录的映射；
- 将最终路径拆分为可读的树状分支；
- 同时显示输出容器、层级模式和重名策略；
- 展示压缩包大小、预计空间和磁盘可用空间；
- 支持在设置中关闭每次开始前的预览。

### 4. 暂停与继续

- Rust 端新增 `TaskControl`，统一管理取消与暂停状态。
- 新增 `pause_job`、`resume_job` Tauri 命令。
- 内置解压器和输出整理过程通过协作式检查点响应暂停。
- 文件、通道和任务中心均提供暂停/继续入口。
- 暂停期间不累计 ETA 有效运行时间。
- 排队任务暂停后不会进入实际解压阶段。

外部 RAR/7Z 进程无法保证进程内部细粒度暂停，只在调用边界响应。

### 5. 文件优先级

- 每个文件支持高、普通、低三级优先级。
- 调度策略先按全局优先级分层，再在每层内应用按通道顺序或轮询策略。
- 恢复任务默认设置为高优先级。

### 6. 通道模板导入导出

- 总设置“模板与维护”新增独立模板导入、导出按钮。
- 模板文件只包含通道预设，不覆盖工作区和全局设置。
- 导入时按模板名称更新或追加。
- 模板文件记录应用版本与导出时间。

### 7. 剩余时间估算

- 任务中心基于当前进度和有效运行时间计算 ETA。
- 暂停时间从估算中扣除。
- 可在“自检与恢复”中关闭。

### 8. 背景焦点拖动

- 外观设置增加背景焦点预览区域。
- 可直接拖动焦点，也可使用水平、垂直滑杆。
- 提供一键居中。
- 焦点与背景填充、对齐、透明度和暗化设置共同生效。

### 9. 总设置重构

- 左侧分类导航支持搜索。
- 新增常规、自检与恢复、说明与版本等分类。
- 标题和侧栏底部显示 `v0.7.0`。
- 支持紧凑侧栏。
- 新增安全、均衡、极速、极简四个设置方案，以及工作区和恢复快捷按钮。

## 可靠性与兼容性

- 配置结构升级至 v7；自动兼容 v1–v6 工作区与预设。
- 任务历史从 v1 自动读取并迁移；旧记录若缺少快照，会明确提示重新导入文件。
- 预检查使用 `fs2` 读取可用磁盘空间。
- 目标目录锁仍使用弱引用缓存。
- 安全删除、归档路径过滤和损坏归档不创建输出目录等 0.6.x 保护继续保留。

## 已知限制

- 中断恢复会重新执行任务，不会从压缩流字节偏移继续。
- 密码正确性通常只能由实际解压器确认；预检查仅提示是否填写密码。
- 磁盘空间估算以压缩包大小乘倍率计算，不等同于归档精确解压后大小。
- 树形预览当前显示最终输出根路径和规则，不枚举归档内部全部文件。
- 外部 `unrar` / `7z` 子进程不支持可靠的进程内暂停。
