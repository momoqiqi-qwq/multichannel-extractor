# 解压台 0.8.4 发布说明

## 解压完成后自动运行 Claude

每个通道的“项目辅助工具”新增独立开关：**解压完成后自动运行 Claude**。

开启后，单个压缩包成功解压时会：

1. 使用该任务后端返回的实际输出目录，而不是手动项目目录或历史目录；
2. 按设置自动创建或刷新 `我的Claude项目.dat`；
3. 检测系统 PATH、npm 全局命令目录与官方 `@anthropic-ai/claude-code` 包；
4. 在新的 Windows 命令窗口中执行 `claude --dangerously-skip-permissions`；
5. 写入启动来源、工作目录、DAT 路径和 PID 日志。

这与用户提供的批处理脚本核心行为一致：工作目录固定为解压结果目录，使用 npm 安装的 `claude.cmd` 或解析到的官方 CLI，并启用跳过权限确认模式。

## 安全与防重复

- 开关默认关闭。
- 首次开启时显示明确的危险参数确认。
- 自动启动不会在每个任务结束时再次弹出确认，以保证真正自动化。
- 同一输出目录在 8 秒内只启动一个 Claude 窗口，避免多个压缩包写入相同目录时连续创建重复窗口。
- 找不到 Claude CLI 时保留开关，但显示安装和检测提示，后续任务会继续尝试。

## 配置与预设

- 自动启动开关按通道持久化。
- 通道复制、配置导入导出、预设保存与应用均保留该选项。
- “应用到全部”会同步此选项。
- “恢复默认”会关闭自动启动，避免危险行为被默认开启。

## 版本

npm、Tauri、Cargo 与应用内版本统一为 `0.8.4`。配置架构仍为 v9；本次字段为向后兼容的可选扩展，旧配置缺失时默认关闭。
