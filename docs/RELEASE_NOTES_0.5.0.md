# 解压台 0.5.0 发布说明

## 关键修复：层级规则看似无效

0.4.0 中，“压缩包同名子文件夹”属于输出容器设置，并且默认开启；“保留结构 / 展平层级 / 跳过外层”只处理压缩包内部路径。因此即使选择“跳过外层”，最终结果外面仍会存在一个由应用创建的压缩包同名文件夹，容易被误认为层级规则没有生效。

0.5.0 将两类规则明确分开：

- **输出容器**：直接写入目标目录，或先创建压缩包同名文件夹。
- **归档层级**：保留结构、展平到深度 N、跳过单一公共根目录。

新安装和从 0.4.x 升级后的默认行为为“直接写入 + 重名文件直接替换”。选择“跳过外层”时，可按全局设置自动关闭同名输出文件夹。

## 后端修复

- 新增 `deduplicateArchiveRoot`：输出文件夹名称与归档单一根目录同名时，自动去掉重复的一层。
- 保留结构、展平深度、跳过外层均增加真实落地目录回归测试。
- 增加重名文件覆盖测试，确认 `overwrite` 会替换原文件内容。
- 处理阶段会在进度消息中说明跳过的是单一外层目录，还是为了避免同名目录重复嵌套。

## 界面与设置

- “输出容器”从高级设置提升到解压位置区域。
- 增加“一键直接覆盖”和“一键独立文件夹”。
- 增加实时“示例输出”路径，切换层级、输出容器和深度时即时变化。
- 展平模式增加完全展平、1 层、2 层、3 层快捷按钮。
- 高级设置增加“避免同名根目录重复嵌套”。
- 全局设置增加“跳过外层时自动直接写入”“显示层级示例”和默认根目录去重。
- 快捷设置可直接切换新通道输出容器与默认重名策略。
- 完成后的文件和通道新增“重新解压”入口；修改层级后无需先移除再导入。
- 已完成通道会明确提示：新设置只影响下一次解压，旧输出不会自动删除，避免把历史文件夹误判为本次层级结果。
- 折叠状态下直接显示“直接写入 / 同名文件夹”“层级模式”和“替换同名”徽标。

## 配置迁移

0.5.0 使用 `multichannel-extractor-state-v5` 和 `multichannel-extractor-presets-v5`。读取旧版本配置时：

- 同名输出文件夹迁移为关闭；
- 重名策略迁移为直接替换；
- 关闭覆盖前确认；
- 开启同名根目录去重；
- 开启“跳过外层时自动直接写入”。

用户仍可在每个通道或全局设置中重新选择安全隔离和自动重命名。
