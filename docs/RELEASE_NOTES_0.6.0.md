# 解压台 0.6.0 发布说明

## 主题

可靠性、任务中心和项目辅助工具。

## 新增

- 持久化任务中心：进度、历史、错误、耗时、写入和替换统计。
- 应用异常退出后将活动任务恢复为“异常中断”。
- 失败/中断/取消/完成任务重新运行。
- 每任务结果 manifest 和安全删除。
- 批量删除全部可删除的解压结果。
- 相同目标目录的任务串行落地。
- 用户提供 BAT 的原样生成。
- 在选定目录一键运行 `claude --dangerously-skip-permissions`。
- Claude 命令启动前确认、BAT 覆盖和生成后打开目录设置。
- 新的水平通道汇聚解压图标。

## 后端可靠性

- `archive.rs` 拆为七个职责模块。
- 覆盖写入使用临时文件和备份交换。
- 归档路径和目标目录符号链接检查。
- 损坏归档不会提前创建最终输出目录。
- 提取报告记录写入、替换和创建目录数量。
- 结果清单位于应用数据目录，不与用户目标目录混放。

## 前端结构

- Store 拆出任务中心、设置、通知、选择器、输出操作、项目工具和配置管理。
- `ChannelCard` 拆出文件队列、输出位置和层级子组件。
- 设置抽屉拆为六个页签组件。
- CSS 按主题、基础、工作区、输出、设置、布局和任务中心拆分。

## 默认与安全

- 同名文件默认直接替换。
- 删除结果默认不删除曾覆盖旧内容的文件。
- Claude 高权限模式默认需要确认。
- 配置和任务历史不保存压缩包密码。

## EXE 名称

暂定为 `JieYaTai.exe`。应用显示名仍为“解压台”。请在发布候选版前确认最终二进制名称。

## 已知限制

- 当前路径锁只序列化完全相同的目标路径，不包含父子目录重叠检测。
- 外部 RAR 工具不能像内部解压器一样即时取消。
- 任务历史仍使用本地前端存储，尚未迁移 SQLite。
- 本交付环境没有 Rust 工具链，未在这里完成动态编译和 Windows 安装包构建。
