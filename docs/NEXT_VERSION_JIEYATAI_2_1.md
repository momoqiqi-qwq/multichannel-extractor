# jieyatai-2.1 建议：工作流编辑器与统一交互

建议下一版优先做四件事：

1. **可视化自动化规则编辑器**：把“扫描目录 → 版本选择 → 解压 → 项目工具 → 完成动作”做成可组合工作流。
2. **统一应用内确认弹窗**：替换现有 `window.confirm` / `window.prompt`，支持危险级别、记住选择和键盘操作。
3. **布局方案保存与导入导出**：用户可以保存“全功能 / 专注 / 自定义”工作区布局，并在设备间同步配置文件。
4. **设置配置驱动**：逐步减少手写设置搜索索引和重复开关模板，让新增设置自动进入搜索、恢复默认和导入导出流程。

其次可考虑：命令面板最近命令排序、自动化运行历史、通道批量编辑和真正的规则触发器。
