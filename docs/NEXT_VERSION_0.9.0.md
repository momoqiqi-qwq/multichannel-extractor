# 解压台 0.9.0 建议规划

## 主题：可视化归档与自动化规则

### 1. 真实归档内容树

在开始前读取压缩包目录，展示完整文件树、大小、路径冲突和最终落地位置。

### 2. 选择性解压

支持按文件、目录、扩展名或规则选择需要解压的内容，并保存为通道模板。

### 3. 关键词规则组

支持包含词、任一词、排除词、正则表达式、版本范围、平台和架构字段，并提供规则测试器。

### 4. 持续目录监控

使用文件系统事件监听下载目录，新文件写入完成后自动扫描、通知或加入队列；提供防抖和稳定文件大小检测。

### 5. 版本策略增强

支持 SemVer、日期版本、构建号、预发布优先级和用户自定义正则捕获组。

### 6. 发布可靠性

建立 Windows CI，执行 Vue 类型检查、Rust 格式化、单元测试、Tauri 构建和安装器冒烟测试。
