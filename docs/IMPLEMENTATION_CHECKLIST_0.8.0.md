## 行为边界

- “最高版本”使用文件名数字版本比较；无法识别时回退到修改时间。
- 默认会自动加入推荐文件，但不会清空不相关队列；关闭“扫描后自动加入”后只展示候选。开启“替换待处理队列”时会移除未开始和已结束项，但保留正在运行或暂停的任务。
- 通道 Claude 按钮没有成功解压输出时会保持禁用；逐文件按钮只在该文件成功且输出未删除时显示。
- 后端会再次验证工作目录存在，避免前端状态过期；生成的 BAT 使用 `where claude`/`call claude`，不包含个人绝对路径。
