# 0.8.1 Claude 按钮热修复

## 问题现象

通道设置中的“生成 Claude DAT”和“用 DAT 打开 Claude”在没有历史成功解压记录时处于禁用状态。用户无法点击按钮，也无法从该位置选择项目目录，形成操作死路。

## 根因

`ChannelCard.vue` 使用 `:disabled="!claudeDirectory"` 控制两个按钮；而 `claudeDirectory` 只从最近一次成功任务的 `outputPath` 计算。即使用户已有项目目录、已配置通道目标目录或愿意手动选择目录，按钮仍然不可用。

## 修复内容

1. 通道中的两个 Claude 按钮不再因缺少历史 `outputPath` 而永久禁用。
2. 有成功解压结果时，继续优先使用最近一次成功任务的实际输出目录。
3. 没有成功解压结果时，点击按钮会弹出目录选择器。
4. 目录选择器按以下顺序给出初始位置：
   - 通道指定输出目录；
   - 最近导入压缩包所在目录；
   - 最近使用的 Claude 工具目录。
5. 选中的目录会写入最近目录与 Claude 工具目录，后续操作可复用。
6. 操作期间显示“处理中…”并暂时禁用重复点击，避免连续弹出选择器或重复启动命令窗口。
7. “总设置 → 项目工具”中的生成与启动按钮也支持未填写路径时先选择目录。

## 兼容性

- DAT 生成仍可在所有支持文件写入的构建中使用。
- Claude 一键启动当前后端仍只在 Windows 构建中启用。
- 启动命令、DAT 文件名和安全确认逻辑没有改变。
