# 0.4.0 发布说明

## 新功能

- 顶栏快捷设置弹层。
- 失败任务批量重试和完成项批量清理。
- 通道轮询 / 按通道顺序两种队列调度方式。
- 重复文件导入策略：忽略、更新、允许重复。
- 全局配置 JSON 导入导出。
- 成功文件单独打开输出目录。
- 通道设置一键应用到全部通道。
- 系统垃圾文件过滤和空目录保留。
- 覆盖前确认、成功/错误通知开关、成功后自动收起。
- 顶栏紧凑、工具栏吸顶、通道编号与文件元信息显示设置。

## 结构改进

- 状态迁移和配置校验移至 `src/domain/state.ts`。
- 任务载荷和轮询调度移至 `src/domain/jobPlanner.ts`。
- 持久化只观察通道配置，不因文件进度、密码和拖放状态重复写入。
- 日志与配置复用通用文本读写 Tauri 命令。

## 后端改进

- 支持过滤 `__MACOSX`、`.DS_Store`、`Thumbs.db`、`desktop.ini` 和 AppleDouble 条目。
- 可保留空目录，并遵守目录深度映射规则。

## 兼容性

- 使用 v4 本地状态键。
- 自动兼容读取 v3、v2、v1 配置。
- 密码和文件队列仍不持久化或导出。
