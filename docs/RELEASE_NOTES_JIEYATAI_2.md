# jieyatai-2 发布说明

发布版本：`jieyatai-2`  
技术版本：`2.0.0`  
配置架构：`v10`

## 工作流与快捷操作升级

- 新增 `Ctrl/Cmd + K` 全局命令面板。
- 命令面板可搜索工作区操作、任务操作、导航入口和设置索引；支持中文、英文和已有缩写。
- 新增 `Ctrl/Cmd + Z` 工作区撤销。
- 顶栏可选显示“撤销”“最近”“命令”三个入口。
- 最近操作抽屉记录结构操作、预设操作和任务启动操作；最多保留 30 条显示记录、15 个撤销快照。
- 撤销快照不会保存通道密码，并会把运行中/排队/暂停状态恢复为已取消，避免产生不存在的后台任务状态。

## 通道自动化方案

每个通道新增四种一键方案：

1. 纯手动：关闭关键词收件和导入后自动开始。
2. 导入即开始：导入压缩包后自动开始，不启用关键词收件。
3. 最新版按需：启用关键词收件，由用户决定何时扫描并开始。
4. 最新版自动：启用关键词收件、导入自动开始，并确保空队列开始时会扫描最新版。

## 预设管理升级

- 重命名已保存预设。
- 复制预设并自动生成不冲突名称。
- 上移/下移调整预设顺序。
- 删除预设保持原有确认流程。
- 保存、应用、删除、重命名、复制、排序均进入撤销快照。

## 布局自由度

新增：

- 工作区宽度：铺满窗口 / 宽屏居中 / 专注窄屏。
- 品牌副标题开关。
- 列标题开关。
- 工具栏统计开关。
- 底部状态栏开关。
- 全局命令入口开关。
- 最近操作入口开关。
- 撤销入口开关。
- 通道自动化方案开关。

原有工作区显示开关继续保留。

## 解压历史

- 顶栏新增“解压历史”入口（可用“解压历史开关”隐藏），按钮上显示已结束任务条数。
- 独立抽屉只展示最近 N 次解压（默认 20 次，可在“设置 · 可靠性”调整为 5/10/20/30/50/100），包含文件名、通道、状态、耗时、写入数与时间，支持搜索、打开目录与重新运行。
- 任务中心仍保留全部历史；“任务历史保留数量”改为下拉预设（50~5000）。

## 通道扫描历史

- 通道卡片操作区新增“历史”按钮（该通道启用关键词扫描，或已留下记录时显示），按钮上带记录条数徽标。
- 每次“扫描最新版并开始”成功后自动记录：扫描时间、收件目录、关键词、扫描文件数、候选数与当时选中的版本；每通道保留最近 30 条，随工作区持久化。
- 每条记录支持：
  - 加入队列：把当时选中的压缩包重新导入并立即开始。
  - 重新扫描：按通道当前关键词重新扫描收件目录。
  - 单条移除；顶部“清空”可清除该通道全部记录。

## 结构优化

- `workspaceHistory.ts`：负责最近操作与撤销快照。
- `channelWorkspaceActions.ts`：负责通道自动化方案和撤销恢复。
- `CommandPalette.vue`：全局命令搜索独立组件。
- `RecentActionsDrawer.vue`：最近操作独立抽屉。
- `ChannelAutomationSettings.vue`：通道自动化方案独立组件。
- `channels.ts` 继续保持在项目 1250 行警戒线以内。
- `ScanHistoryPopover.vue`：通道扫描历史独立弹出层组件。
- `commands_preflight.rs`：`preflight_jobs` 从前 `commands.rs` 拆出，`commands.rs` 回到 650 行警戒线以内。

## 兼容性

本版本使用：

- `multichannel-extractor-state-v10`
- `multichannel-extractor-presets-v10`

读取时仍兼容 jieyatai-1 的 v9 存储键以及更早版本。
