## 覆盖场景

- 新通道默认关闭自动运行。
- 旧通道或旧预设缺失字段时默认关闭。
- 开关启用前显示危险模式确认；取消时不保存。
- 成功解压后使用事件中的实际输出目录。
- 解压失败、取消或没有输出目录时不启动。
- 自动运行不显示逐任务确认。
- CLI 检测失败时提示用户，但不破坏解压完成状态。
- 同一目录短时间重复完成时只创建一个窗口。
- 不同输出目录可分别启动。
- 通道预设、复制、应用到全部和持久化包含开关。
