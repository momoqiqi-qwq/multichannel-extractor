# 解压台 0.8.0 发布说明

## 版本主题

0.8.0 聚焦“自动收件、可靠项目启动与高度可定制背景”。本版新增每通道关键词扫描、最高版本选择、系统下载目录接入、Claude CLI 检测与新控制台启动、背景高级调节和更多批量入口。

## 新功能

### 1. 每通道关键词收件

- 每个通道独立配置扫描目录和关键词。
- 支持“包含全部关键词”与“包含任一关键词”。
- 支持扫描子目录，最大深度 12 层。
- 支持排除或包含 alpha、beta、rc、preview、nightly 等预发布文件。
- 可一键使用系统下载目录。
- 主工具栏、快捷设置、总设置和通道卡片均有扫描入口。
- 支持启动后自动扫描已配置通道。

### 2. 最高版本选择

- 后端从文件名识别 `version`、`release`、`版本`、`ver`、`v` 后的数字序列。
- 数字逐段比较，`2.10.0` 高于 `2.9.9`。
- 版本相同或无法识别时按最后修改时间选择。
- 扫描结果先展示 5 个快捷候选，并可展开本次保留的全部候选。
- 支持“扫描后自动加入推荐文件”或“仅预览候选后手动确认”。
- 支持打开扫描目录、清除结果和手动将任意候选加入队列。

### 3. Claude 启动修复

- 通道按钮只使用最近一次成功解压产生的 `outputPath`。
- 每个成功文件旁新增 Claude 按钮，精确使用该文件自己的 `outputPath`。
- 启动前验证目录真实存在。
- 可先执行 `where claude` 与 `claude --version`。
- Windows 使用 `CREATE_NEW_CONSOLE` 创建独立命令窗口。
- 新进程的 `current_dir` 设置为实际解压目录。
- 执行 `claude --dangerously-skip-permissions`，并返回 PID。
- 可选启动前自动写入项目 BAT；BAT 使用系统 PATH 检测 Claude，不包含开发机绝对路径。

### 4. 自定义背景增强

- 新增背景缩放、亮度、对比度、饱和度、暗角和遮罩颜色。
- 保留焦点拖拽、X/Y 调节、填充方式、透明度、暗化和模糊。
- 新增清晰原图、文字优先、柔和虚化和鲜艳展示四个预设。
- 通道穿透开关与通道不透明度独立设置。
- 快捷设置新增背景可见度滑杆。

### 5. 体验改进

- 设置中心新增“关键词收件”分类。
- 搜索通道时同时匹配关键词和扫描目录。
- 通道设置采用响应式收件卡片，显示版本、格式、大小和选择状态，并支持展开完整候选。
- Claude 工具页新增 CLI 状态卡、自动 BAT、启动前检测开关和准确命令预览。
- 新增 `Ctrl+Shift+F` 扫描全部关键词通道。

## 配置迁移

- 应用配置结构升级至 v8。
- 工作区键：`multichannel-extractor-state-v8`。
- 预设键：`multichannel-extractor-presets-v8`。
- v7 及更早配置会自动归一化，新增字段使用安全默认值。

## 已知限制

- 关键词只匹配文件名，不读取压缩包内部内容。
- 版本识别以数字序列为主，复杂自定义版本规则可能需要手动选择候选。
- 目录扫描是用户触发或启动时触发，不是持续文件系统监听。
- Claude 一键新控制台启动当前只在 Windows 构建中启用。
- `--dangerously-skip-permissions` 具有高风险，只应在可信目录使用。
