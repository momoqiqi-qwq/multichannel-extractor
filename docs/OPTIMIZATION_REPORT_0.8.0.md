# 0.8.0 UX 优化报告

## 主要问题与处理

### 下载目录里文件多，用户难以找到正确版本

为每个通道增加独立收件规则。扫描后直接突出最高版本，同时支持自动加入、仅预览、完整候选折叠和手动加入，减少误选和重复拖放。

### 自动行为不透明

扫描结果明确显示扫描文件数、匹配数、选择原因、扫描时间、版本号和最终选择。全局扫描完成后汇总匹配通道数。

### Claude 按钮缺少可诊断信息

新增 CLI 检测、可执行文件路径、版本信息、启动工作目录、命令和进程 PID。修复旧 BAT 中的开发机绝对路径，并为每个成功文件提供精确输出目录启动按钮。失败提示指向“项目工具”检测入口。

### 背景图可见性与可读性冲突

将背景图和通道面板拆成两套控制：背景可调色彩、缩放和暗角；通道单独调不透明度。快速预设帮助用户在“展示背景”和“文字清晰”之间快速切换。

### 设置入口较深

新增总设置分类、主工具栏按钮、快捷设置按钮和 `Ctrl+Shift+F`；通道结果区还提供打开扫描目录、清除结果和完整候选展开，常用操作不必来回切换。

## 后续可继续改进

- 关键词规则组与排除关键词。
- 持续目录监听与系统通知。
- 候选详情抽屉和规则命中高亮。
- 自定义背景裁剪预览和多背景轮换。
- Claude 启动健康检查与终端类型选择。
