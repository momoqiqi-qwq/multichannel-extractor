# 解压台 0.6.1 发布说明

## 启动体验

- Windows 构建使用 GUI 子系统启动。
- 正常双击 `JieYaTai.exe` 时不再创建额外命令行/终端窗口。
- 调试日志建议通过开发终端、WebView DevTools 或后续日志文件功能查看。

## 个性化设置

“设置 → 个性化”新增：

- 7 种字体方案，包括系统默认、微软雅黑、Segoe UI、Noto/思源、衬线、等宽和自定义字体。
- 400/500/600/700 四档字重。
- 本地图片背景选择；选中后复制到应用专用数据目录，避免原图移动导致背景失效。
- 背景覆盖、完整显示或拉伸填满。
- 居中、顶部、底部、左侧、右侧对齐。
- 图片透明度、背景暗化与模糊强度。
- 一键清除背景和恢复默认外观。

自定义字体只引用系统已安装字体，不会打包或复制字体文件。背景图片会复制到应用专用数据目录，配置只保存复制后的本地路径。

## 性能与结构

- 外观设置应用逻辑迁移到 `src/services/appearance.ts`，Store 不再直接维护大量 DOM 属性。
- 工作区持久化改为 180ms 合并写入，减少滑块、输入框连续变化产生的同步 localStorage 写入。
- 退出前主动刷新一次持久化状态，兼顾性能和数据完整性。
- Rust 目标目录信号量缓存改为 `Weak<Semaphore>`；历史目录任务结束后可以释放，避免目录种类持续增长时缓存永久膨胀。

## 兼容性

- 沿用 v6 配置结构，旧的 0.6.0 设置会自动补齐新增个性化默认值。
- 不改变现有通道、预设、任务历史和解压结果清单格式。
