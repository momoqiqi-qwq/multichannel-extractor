# 下一版本建议：0.8.0

建议 0.8.0 的主题定为：**归档内容可视化与可验证恢复**。

## P0：发布可信度

1. 建立 Windows CI：`npm ci`、`vue-tsc`、Vite、`cargo fmt`、`cargo check`、`cargo test`、Tauri 构建。
2. 为预检查、优先级调度、恢复快照和暂停状态机补充自动化单元测试。
3. 增加崩溃注入测试：在排队、解压、整理、写清单阶段强制退出，再验证恢复和清理行为。
4. 增加版本内升级测试，覆盖 v5、v6 到 v7/v8 的配置与任务历史迁移。

## P1：归档内容树与选择性解压

1. 开始前读取归档条目，显示真实文件夹树、文件数、未压缩总大小和最大文件。
2. 支持勾选文件夹或文件后选择性解压。
3. 在预览中标记路径冲突、危险路径、重复文件和疑似垃圾目录。
4. 提供搜索、扩展名筛选、只看冲突项和只看大文件。

这会把 0.7.0 的“输出根路径树”升级为真正的“归档内容→最终落地路径”预览。

## P1：更真实的恢复

1. 为可分块、可随机访问的格式研究条目级检查点，记录已成功写入的条目。
2. 恢复时跳过已校验完成的条目，而不是从头重跑整个任务。
3. 对每个已写入文件记录大小、时间和可选哈希，防止把不完整文件误判为完成。
4. 明确区分“任务重试”“条目级恢复”“格式原生断点”三种能力。

不要把不支持随机恢复的流式格式包装成真正字节级断点续解。

## P1：队列调度增强

1. 支持拖动重排任务，并显示实际全局执行顺序。
2. 支持“本任务完成后再开始”“同盘限速”“同目录互斥”等依赖规则。
3. 支持每通道并发上限和磁盘级并发上限。
4. 增加暂停全部、继续全部、仅运行高优先级按钮。
5. 记录历史吞吐量，改进 ETA 并显示可信区间。

## P2：安全与可观测性

1. 预检查读取归档元数据后给出更准确的未压缩大小和压缩比异常警告。
2. 增加压缩炸弹保护：最大展开大小、最大文件数、最大层级、单文件上限。
3. 增加磁盘写入失败、权限不足、路径过长和杀毒软件占用的诊断建议。
4. 任务详情展示各阶段耗时：等待锁、等待并发、读取、解压、整理、清单写入。
5. 导出可脱敏的诊断包，不包含密码和用户文件内容。

## P2：模板与个性化

1. 模板分组、标签、固定、搜索、预览和冲突处理选择。
2. 背景增加裁剪预览、每主题独立背景和多显示器缩放适配。
3. 设置搜索可直接定位到具体选项，并高亮匹配内容。
4. 支持快捷键自定义与冲突检测。

## 推荐交付顺序

第一阶段先完成 CI 和真实归档内容读取；第二阶段做选择性解压与条目级恢复；第三阶段增强队列依赖和诊断。这样 0.8.0 的新能力可以建立在可重复验证的发布流程上，而不是继续只增加界面按钮。
