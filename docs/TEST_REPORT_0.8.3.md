# 0.8.3 测试报告

## 已执行

- 版本一致性检查。
- 既有配置、布局、0.8.1 与 0.8.2 回归静态检查。
- 0.8.3 通道目录与 npm Claude CLI 专项静态检查。
- Vue/TypeScript 源文件基础语法与标记检查。
- ZIP 完整性检查。

## 重点覆盖

- 通道项目工具不会调用目录选择器。
- 指定目录与跟随压缩包两种模式均可确定工作目录。
- npm 全局前缀、全局模块根目录、官方包 bin 与 Windows 原生包均有探测路径。
- CLI 状态序列化包含来源字段。
- 启动器使用解析出的 CLI，而不是仅依赖 `claude` 在 PATH 中可见。

## 环境限制

当前交付环境没有 Rust/Cargo，无法执行 `cargo check`、Rust 单元测试和 Windows 命令窗口实机验证。项目依赖未预装，因此正式 `vue-tsc` 与 Vite 构建需要在安装依赖后执行。
